Perangkat Lunak (Software)

Perangkat lunak adalah data yang diformat dan disimpan secara digital — termasuk program komputer beserta dokumentasinya — yang bisa dibaca dan ditulis oleh komputer. Berbeda dengan hardware, software tidak berwujud fisik.

Ringkasan Bagian

Bagian ini membagi software dari dua sudut pandang. Berdasarkan lisensinya, software dibedakan menjadi freeware, shareware, adware, dan commercial/proprietary software. Berdasarkan fungsinya, software dibedakan menjadi sistem operasi (berbasis CUI seperti DOS dan Unix, atau berbasis GUI seperti Windows, Linux, dan Mac OS) dan program aplikasi (pengolah kata, spreadsheet, grafis, bahasa pemrograman, database, hingga layanan internet).

1. Berdasarkan Lisensinya, Software Dibagi Sebagai Berikut

a. Freeware

Software yang gratis untuk digunakan, tanpa batasan jumlah dan waktu pemakaian. Contohnya seperti Skype, Avira, CCleaner, dan Smadav.

b. Shareware

Software yang dapat diunduh dan digunakan hanya untuk dicoba sementara hingga batas waktu tertentu. Contohnya seperti Corel Draw, Microsoft Office, dan IDM (Internet Download Manager).

c. Adware

Software yang gratis, tetapi menampilkan iklan ketika dijalankan. Contohnya seperti Windows Live Messenger Plus.

d. Commercial/Proprietary Software

Software yang dibuat untuk dijual dan berbayar kepada pengembangnya serta dilindungi hak ciptanya. Contohnya seperti Microsoft Windows, Adobe Photoshop, Adobe Flash, dan Kaspersky.

2. Berdasarkan Fungsinya, Software Terbagi Menjadi Beberapa Jenis

a. Sistem Operasi (Operating System)

Sistem operasi dibuat untuk mengendalikan dan mengoordinasikan seluruh kegiatan dari sistem komputer. Berdasarkan basisnya, sistem operasi dikategorikan sebagai berikut.

1) Berbasis CUI (Character User Interface)

Sistem operasi berbasis teks, di mana pengguna berinteraksi menggunakan perintah-perintah berupa teks. Yang paling sering dijumpai adalah DOS (Disk Operating System) dan Unix OS.

2) Berbasis GUI (Graphical User Interface)

Ciri khasnya adalah pengguna berinteraksi melalui gambar-gambar/simbol-simbol tertentu sehingga lebih memberi kemudahan dan kenyamanan (user friendly). Contoh sistem operasi berbasis GUI adalah Windows, Linux, Mac OS, dan Unix.

Sistem OperasiDeskripsi
Windows Memiliki kemampuan menjalankan beberapa program secara serempak dalam bentuk jendela-jendela yang dapat dipindah dari satu program ke program lainnya (multitasking). Jenis-jenisnya antara lain Windows 8, Windows 10, dan Windows 11.
Linux Menggunakan logo seekor pinguin (bernama TUX), berbasis UNIX, dan merupakan hasil pengembangan freeware dan open source. Berbagai jenis Linux OS disebut Distro Linux, misalnya Debian Linux, Redhat Linux, dan CentOS Linux.
Mac OS Sistem operasi komputer buatan Apple, pertama kali dirilis Januari 1984. Apple mengawali revolusi komputer pribadi tahun 1970-an dengan Apple II, dan sejak 1980-an berubah menjadi Macintosh.

b. Program Aplikasi

Program aplikasi merupakan perangkat lunak siap pakai yang membantu melaksanakan pekerjaan penggunanya, disiapkan sesuai kebutuhan masing-masing.

Jenis AplikasiFungsiContoh Program
Pengolah Kata (Word Processing) Mengolah kata — mengetik, membuat, mengedit, menyimpan, dan mencetak dokumen. Microsoft Word, OpenOffice Writer, WordPad, WPS Office, Notepad, dan lainnya.
Pengolah Lembar Kerja (Spreadsheet) Membuat dan mengelola atau memanipulasi lembar kerja secara elektronik. Microsoft Excel, Kspread, Google Sheets, dan lainnya.
Pengolah Grafis Mendesain poster, iklan, dan sejenisnya. Adobe Photoshop, CorelDraw, Adobe Illustrator, dan lainnya.
Bahasa Pemrograman Penghubung komunikasi antara komputer dan manusia (programmer). Pascal, Java, C++, Scratch, dan lainnya.
Pengolah Data (Database) Mengolah data berjumlah banyak dalam bentuk basis data, misalnya data pegawai atau data barang. Microsoft Access, MySQL, Oracle 10g, dan lainnya.
Layanan Internet Mengakses berbagai layanan internet. Surel, WWW, peramban, FTP, dan lainnya.
